Clés des notifications

Ces clés sont générées dans votre navigateur : rien n'est envoyé sur Internet. À faire une seule fois.

Ne mettez jamais la clé privée dans config.js, sur GitHub ni dans un message.

Ensuite

  1. Collez la clé publique dans config.js (VAPID_PUBLIC_KEY) et publiez.
  2. Dans Supabase → Edge Functions → Secrets, ajoutez VAPID_PUBLIC_KEY et VAPID_PRIVATE_KEY.
  3. Suivez la suite dans le README, section « Notifications ».
